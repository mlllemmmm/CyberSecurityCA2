Model comparison

Six classifiers named in the case study's literature review, trained on the same balanced 12,000-flow train / 4,000-flow test split of the real CICDDoS2019 sample. The live demo above runs the Decision Tree, since its splits are simple threshold checks that translate directly into browser JS.

This mirrors what the case study reports: Random Forest and XGBoost lead, the single Decision Tree is close behind, and Logistic Regression trails — because the "DrDoS" class here merges 8 different reflection protocols (DNS, LDAP, MSSQL, NetBIOS, NTP, SNMP, SSDP, TFTP) into one label, and that combined class isn't linearly separable from the others the way a single-protocol attack is.

Trained on a real, user-provided CICDDoS2019 sample (44,000 flows, CIC flow-level features), class-balanced to 16,000 flows across Benign / SYN Flood / UDP Flood / DrDoS before the 75/25 split. Built to illustrate the detection pipeline described in the case study (data collection → preprocessing → feature selection → model training → evaluation). Not intended for production traffic filtering.
